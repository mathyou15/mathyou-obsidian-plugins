# Prism Print

Плагин для печати и PDF в цветах Prism.

Better Export PDF по умолчанию переключает страницу на светлую тему. Тёмный Prism уходит в белый лист, а текст, теги и блоки теряют контраст. Prism Print оставляет ту же тему, что на экране: тёмный фон остаётся тёмным, светлый — светлым, цвета печатаются как есть.

## Использование

Включите плагин рядом с Better Export PDF. В настройках экспорта включите «Print background» / «Печать фона», иначе браузер выкинет заливку страницы.

Отдельных команд нет: он сам подхватывает окно предпросмотра и печати.

## Совместимость

Работает с темой Prism в светлой и тёмной схеме. Имеет смысл держать вместе с Prism Adaptive Tags и Math Pages Palette.
