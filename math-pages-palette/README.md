# Math Pages Palette

Плагин, нацеленный на создание красивых математических конспектов.

Благодаря ему можно создавать академические блоки с проработанными иконками и цветами.

## Использование

Откройте контекстное меню редактора:

**Пкм** $\rightarrow$ **Палитра** $\rightarrow$ **Академический блок**

Затем выберите нужный тип. Если заранее выделить текст, плагин сразу поместит его внутрь нового блока.

Блок также можно вставить через команду **«Вставить академический блок»**.

## Доступные блоки

- Определение — `> [!определение]`
- Теорема — `> [!теорема]`
- Лемма — `> [!лемма]`
- Замечание — `> [!замечание]`
- Пример — `> [!пример]`
- Свойства — `> [!свойства]`
- Соглашение — `> [!соглашение]`
- Доказательство — `> [!доказательство]`
- Следствие — `> [!следствие]`
- Интуиция — `> [!интуиция]`
- Контекст — `> [!контекст]`
- Загадка — `> [!загадка]`
- Билет — `> [!билет]`

## Совместимость

Плагин использует обычный Markdown-синтаксис callout-блоков Obsidian. Он также синхронизирует свои стили в CSS-сниппет для совместной работы с Cluddle Callouts.
