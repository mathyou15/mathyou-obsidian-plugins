# Iconize Revival

Дополнение для [Iconize](https://github.com/FlorianWoelki/obsidian-iconize), которое возвращает нормальное редактирование shortcode-иконок в Live Preview.

Оригинальный Iconize заменяет весь диапазон `:LiActivity:` атомарным SVG. Из-за этого курсор перепрыгивает код, вертикальная навигация смещается, а выделение строки дёргается. Iconize Revival оставляет иконку свёрнутой только вне активного диапазона.

## Поведение

- Кликните по иконке – откроется исходный `:IconName:`.
- Стрелки влево и вправо свободно входят в shortcode.
- Стрелки вверх и вниз сохраняют настоящую текстовую колонку.
- Частичное и сквозное выделение раскрывает затронутые shortcode.
- После выхода курсора иконка снова отображается.
- Autocomplete, Reading View, иконки файлов, папок, вкладок и ссылок остаются штатными функциями Iconize.

## Требования

- Obsidian 1.5 или новее.
- Установленный и включённый Iconize 2.14.7.

Iconize Revival автоматически перезагружает Iconize при включении, чтобы заменить только его редакторский модуль. При выключении Revival штатный модуль Iconize автоматически восстанавливается.

## Установка

1. Установите и включите Iconize 2.14.7.
2. Скопируйте папку `iconize-revival` в `<ваш-сейф>/.obsidian/plugins/`.
3. Перезапустите Obsidian.
4. Включите Iconize Revival в разделе «Сторонние плагины».

## Совместимость

Плагин намеренно привязан к Iconize 2.14.7, потому что заменяет конкретный редакторский extension этой версии. При другой версии Revival остановится с уведомлением и не изменит работу Iconize.
