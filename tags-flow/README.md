# Tags Flow

Плагин возвращает стрелкам нормальный ход по строкам с тегами.

В режиме редактирования курсор больше не перескакивает строку: можно идти вверх, вниз и вдоль текста как обычно, а не только мышкой.

## Совместимость

Работает вместе с Prism Adaptive Tags и Tags for Markdown. Другие плагины не нужны.
