# Tags Flow

Плагин возвращает стрелкам нормальный ход по строкам, оформленным через Tags for Markdown.

В режиме редактирования курсор больше не перескакивает строку: можно идти вверх, вниз и вдоль текста как обычно, а не только мышкой.

## Совместимость

Предназначен для оригинального плагина Tags for Markdown версии 1.3.0.
