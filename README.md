# MathYou Obsidian Plugins

Коллекция плагинов для красивых и структурированных математических конспектов в Obsidian. Академические блоки и цветовые акценты объединены в одной удобной палитре.

## Плагины

### Math Pages Palette

Добавляет академические блоки с тщательно подобранными цветами и иконками: определения, теоремы, доказательства, примеры и другие элементы математического текста.

[Документация](./math-pages-palette/README.md)

### Prism Adaptive Tags

Добавляет компактные цветные теги для дат, статусов и смысловых акцентов. Палитра гармонично выглядит в светлой и тёмной темах Prism.

[Документация](./prism-adaptive-tags/README.md)

## Установка

1. Скачайте репозиторий.
2. Скопируйте нужные папки в `<ваш-сейф>/.obsidian/plugins/`.
3. Перезапустите Obsidian.
4. Включите плагины в разделе «Сторонние плагины».

Для общего меню «Палитра» установите оба плагина.
