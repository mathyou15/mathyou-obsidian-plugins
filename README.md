# MathYou Obsidian Plugins

Коллекция плагинов для красивых и структурированных математических конспектов в Obsidian. Академические блоки и цветовые акценты объединены в одной удобной палитре.

## Плагины

### Math Pages Palette

Добавляет академические блоки с тщательно подобранными цветами и иконками: определения, теоремы, доказательства, примеры и другие элементы математического текста.

[Документация](./math-pages-palette/README.md)

### Prism Adaptive Tags

Добавляет компактные цветные теги для дат, статусов и смысловых акцентов. Палитра гармонично выглядит в светлой и тёмной темах Prism.

[Документация](./prism-adaptive-tags/README.md)

### Tags Flow

Возвращает стрелкам нормальный ход по строкам с тегами. В режиме редактирования курсор больше не перескакивает строку.

[Документация](./tags-flow/README.md)

### Iconize Revival

Возвращает нормальное редактирование shortcode-иконок Iconize. Курсор и выделение свободно входят в `:IconName:`, а вне активного диапазона снова показывается SVG.

[Документация](./iconize-revival/README.md)

### Prism Print

Печать и PDF в цветах Prism. Тёмная тема остаётся тёмной, светлая — светлой, текст и теги не выцветают.

[Документация](./prism-print/README.md)

## Установка

1. Скачайте репозиторий.
2. Скопируйте нужные папки в `<ваш-сейф>/.obsidian/plugins/`.
3. Перезапустите Obsidian.
4. Включите плагины в разделе «Сторонние плагины».

Для общего меню «Палитра» установите Math Pages Palette и Prism Adaptive Tags. Tags Flow имеет смысл держать включённым вместе с тегами, а Iconize Revival – рядом с Iconize 2.14.7. Для PDF в цветах Prism включите Prism Print рядом с Better Export PDF.
