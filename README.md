# MathYou Obsidian Plugins

Два небольших плагина для аккуратных математических конспектов в Obsidian.

## Плагины

### Math Pages Palette

Добавляет академические callout-блоки с продуманными цветами и иконками: определения, теоремы, доказательства, примеры и другие элементы математического текста.

[Документация](./math-pages-palette/README.md)

### Prism Adaptive Tags

Добавляет компактные цветные теги, которые автоматически адаптируются к светлой и тёмной темам Prism. Теги можно вставлять из общего меню «Палитра» или коротким синтаксисом.

[Документация](./prism-adaptive-tags/README.md)

## Установка

1. Скачайте репозиторий.
2. Скопируйте нужные папки в `<ваш-сейф>/.obsidian/plugins/`.
3. Перезапустите Obsidian.
4. Включите плагины в разделе «Сторонние плагины».

Для общего меню «Палитра» установите оба плагина.
